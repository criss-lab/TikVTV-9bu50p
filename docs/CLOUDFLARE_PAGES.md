# Cloudflare-only frontend hosting for streamora.co.ke

Connect GitHub repository `criss-lab/TikVTV-9bu50p` in Cloudflare Workers & Pages → Create → Pages → Import existing Git repository. Set production branch to `feature/pesapal-premium-integration` while the integration is being tested; switch to the merged production branch only after review. Build command: `npm ci && npm run build`; output directory: `dist`; root: `/`. Add `VITE_SUPABASE_URL` and `VITE_SUPABASE_ANON_KEY` as Pages build environment variables (these are public client configuration; NEVER add PesaPal consumer secrets to VITE variables). The `public/_redirects` file makes deep links such as `/payment-callback` resolve to the SPA.

Once the Pages deployment is healthy, add `streamora.co.ke` under Pages → Custom domains. Because DNS is already Cloudflare-managed, follow Cloudflare's prompted DNS association and verify certificate provisioning. Inspect/remove old Vercel A/CNAME records only during cutover. Verify `https://streamora.co.ke/`, `/profile`, `/premium`, and `/payment-callback` before disabling the old Vercel project. Configure the authenticated backend PesaPal callback URL and registered IPN separately, then test with a real low-value authorized payment. Keep the existing Supabase-compatible backend unless intentionally migrating its database/functions too.
